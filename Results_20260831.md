# Template comparison results

Run: 4,252 production searches, three templates, result sizes 10 and 20.

## Volume returned is effectively identical

- At size 10: default 10.0, mc-tiers-dobb 10.0, mc-tiers-nameb 9.8 identities per search
- At size 20: default 20.0, mc-tiers-dobb 20.0, mc-tiers-nameb 18.3
- mc-tiers-nameb is the only one that falls short, and only at size 20

## Top hit changes on about 14% of searches

- default vs mc-tiers-dobb: 85.8% same top hit at size 10, 85.1% at size 20
- default vs mc-tiers-nameb: 86.9% at size 10, 86.2% at size 20
- mc-tiers-dobb vs mc-tiers-nameb: 87.2% at size 10, 86.2% at size 20
- Between 545 and 634 searches per pair returned a different first result

## Result sets overlap only about half the time

- default vs mc-tiers-dobb: 47.5% overlap at size 10, 44.2% at size 20
- default vs mc-tiers-nameb: 50.7% at size 10, 50.0% at size 20
- mc-tiers-dobb vs mc-tiers-nameb: 57.7% at size 10, 57.3% at size 20

## mc-tiers-nameb returns fewer results more often

- 253 searches returned fewer than default at size 10, 851 at size 20
- default returned fewer on 0 searches
- mc-tiers-dobb is level with default, 4 searches fewer at size 10 and 5 at size 20

## Where mc-tiers-nameb falls short, by file

- uipath.csv at size 20: 14 identities per search against 20 for the other two
- cris.csv at size 10: 9.6 per search, 13 searches returned one only and 4 returned none
- bhub-c.csv at size 20: 19.9 per search, minimum 3
- All other files return the full 10 or 20 for all three templates

## Distinct identities across the run, size 10, all criteria

- default 78,479
- mc-tiers-nameb 70,494
- mc-tiers-dobb 70,478

## Searches returning nothing

- default: 2 at size 10
- mc-tiers-nameb: 14 at size 10, mostly CRIS and UIPATH
- mc-tiers-dobb: 0
